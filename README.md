## 🧬 THE CONCEPT

> **What happens when technology stops being a tool — and becomes part of you?**

**CYBORG** explores a futuristic visual identity for **Techfest 2026**, blending human-machine aesthetics with an immersive digital interface.

The goal was simple:

**Make the first interaction feel like entering the future.**
