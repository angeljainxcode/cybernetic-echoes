# Augment Reality

Build a premium, highly interactive Cyborg-themed landing page for Techfest, IIT Bombay.

I have attached a visual reference. Use it as the primary art-direction reference for composition, visual language, typography hierarchy, color behavior, section structure and overall atmosphere.

IMPORTANT:
Do NOT simply reproduce the image as a static website.
Turn the visual concept into a REAL, responsive, interactive web experience.

CONCEPT

HUMAN // MACHINE

The experience explores the evolving relationship between human intelligence and technology.

The website should feel like a cutting-edge interactive technology exhibition, not a conventional event website.

Think:
Apple-level product presentation + experimental digital art + IIT-level technology + Techfest energy.

COLOR SYSTEM

Do NOT make this boring monochrome cyberpunk.

Use a dark obsidian foundation:

#050505

Primary text:

#F5F5F5

Accent colors:

ELECTRIC CYAN — #00E5FF
ACID LIME — #B6FF00
HOT MAGENTA — #FF2BD6

IMPORTANT:
Do NOT use all colors everywhere.

Color should evolve through the experience:

HERO → CYAN
AUGMENT → ACID LIME
INTELLIGENCE → CYAN
CREATION → MAGENTA
FINAL → colors collide → return to black and white

Avoid rainbow gradients and excessive neon glow.

Color should feel intentional and cinematic.
